# Sucrélya – site vitrine (maquette)

Proposition de site internet pour **Sucrélya**, bar à desserts au 4 rue Pasteur, 59400 Cambrai.
Réalisé par [NK Digital](https://nkdigital.fr).

> ⚠️ Maquette en attente de validation par Sucrélya. Logo, photos et avis appartiennent à l'établissement : dépôt à garder privé tant que l'accord n'est pas donné.

## Contenu

- `index.html` : le site complet (HTML + CSS + JS dans un seul fichier, aucune dépendance à installer)
- `img/` : photos

## Sections

Accueil avec statut ouvert/fermé en direct · bandeau « En ce moment » · Notre univers · Carte à onglets · Engagement (Octobre Rose) · Instagram · Avis Google · Événements (formulaire de demande par e-mail) · Horaires, contact et plan Google Maps · Barre d'actions mobile (Appeler, Itinéraire, Instagram).

## Mise en ligne (Cloudflare Pages)

1. Cloudflare → Workers & Pages → Créer → Pages → Connecter à Git → choisir `maquette-sucrelya`
2. Framework : **Aucun** · Commande de build : *(vide)* · Répertoire de sortie : `/`
3. Déployer
